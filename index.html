  • timelikein development

    updated

    A containerised shell for AI coding agents: tools built for a user with no terminal, a limited context window and nobody watching, behind one output contract.

    Coding agents work in a shell made for people. They hand-build pipelines to keep output small, retry commands that don't exist, wait on processes that never return, and stop at anything that needs infrastructure. Then a person steps in to unstick, clean up or bring something up.

    timelike aims for the agent to finish a task without that help (tests passing, a running app, a reachable deployment), and, when it can't, to say exactly why and who can unblock it.

    Seven governing principles: Unaided completion · Every call concludes · Found where agents look · Reach only by grant · Wrong turns are recoverable · Claims are measured · Harness-agnostic
